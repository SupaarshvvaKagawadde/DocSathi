# Research sources and evidence limits

Checked for this plan on 9 October 2026. Observations are dated research, not perpetual product rules.

## Official application reference

[UCEED 2026 registration](https://www.uceed.iitb.ac.in/2026/registration.html) describes JPEG photo/signature uploads, PDF documentary evidence, and conditional supporting documents. A name difference from the Class XII certificate requires name-change evidence in that historical instruction set. This demonstrates why a packet checker must model conditions as well as formats.

The 2026 page is a historical example. It does not establish the instructions for a future application cycle. The eventual live pack must review the current brochure, registration instructions and subsequent official updates. This plan deliberately avoids treating third-party upload limits as authoritative UCEED rules.

## Observed alternative

[UploadPrep CEED registration](https://www.uploadprep.com/india/ceed/registration) presents preparation controls for photographs, signatures and documentary uploads. The observed page supports positioning research around upload preparation. It does not prove the company's complete product scope, market share, prices or inability to add packet review.

## Upload security reference

[OWASP File Upload Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html) supports defense in depth for untrusted file handling: type checking, access control, size limits, storage separation and safe processing. JKY-Folder's proposed quarantine, isolation and provenance architecture is a product-specific design choice requiring its own security review.

## Accessibility reference

[W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) is the standards reference for the proposed AA accessibility target. A target is not conformance evidence. The eventual implementation needs manual and automated assessment of its actual user journeys.

## Indian privacy reference

[MeitY notified DPDP Rules 2025](https://www.meity.gov.in/static/uploads/2025/11/53450e6e5dc0bfa85ebd78686cadad39.pdf) is a primary notified text with staged commencement. The eventual legal review must map provisions to launch dates, applicable amendments, data classes, processors and the actual operating model.

[PIB official explanation](https://www.pib.gov.in/PressReleasePage.aspx?PRID=2198217&lang=1&reg=3) confirms notification and an implementation timeline. Neither this research nor the implementation plan is a compliance certification. Proposed safeguards may precede legal commencement; counsel must determine the obligations actually in force.

## Trademark reference

[WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database/index) provides name and image search resources and points to national or regional register searches. The generated logo is an original design concept. No comprehensive trademark search or legal clearance was completed, so global uniqueness is not claimed.

## Evidence classification

Verified observation: a feature or instruction visible in the linked source at review time.
Proposed decision: a product, system or operating choice authored for JKY-Folder.
Planning assumption: a budget, schedule, price, threshold or conversion scenario requiring validation.
Deferred review: legal applicability, procurement quotes, production stack versions or trademark clearance to perform at the appropriate implementation gate.

Recheck all time-sensitive sources before producing a live rule pack or making a public product claim.
